# Ouro & Fio — Studio de Cabelo

React + Vite + Capacitor + Supabase (Auth, banco com RLS e login com Google).

```bash
npm install
npm run dev
```

- Banco e RLS: `supabase/schema.sql`
- Login, Google OAuth e checklist de evidências: `AUTH_SETUP.md`
- Variáveis de ambiente: `.env.local` (não vai para o GitHub; modelo em `.env.local.example`)
